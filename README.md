~# Veterinary Clinic Management System

The Veterinary Clinic Management System (VCMS) is a web-based application developed to improve the management of veterinary clinics by replacing manual record-keeping with a secure digital system.

The application enables clinic staff and doctors to efficiently manage patient information, medical records, and daily clinical operations through role-based access.

## Technology Stack

- React.js
- Node.js
- Express.js
- Supabase PostgreSQL
- Git
- GitHub
